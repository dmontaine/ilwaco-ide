# FiveInARow — requirements

An example program shipped with Ilwaco IDE. Open `FiveInARow.vfp` in the IDE and build it.

## Tested

**Builds and opens its window on Linux/GTK3** — Debian 13, x86_64, verified 2026-08-07 with
Ilwaco's bundled FreeBASIC toolchain. It was compiled and launched, and a window appeared. Nothing
here says the program behaves *correctly* beyond that: no buttons were pressed.

It came from Astoria, Ilwaco's Windows sibling, where it built on 64-bit Windows 11.

## What you need to run it

Nothing beyond Ilwaco itself — no hardware, no network, and none of the optional
control libraries.
